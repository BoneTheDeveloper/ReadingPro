# User Flows

These docs describe what a **learner** does and sees — one action at a time. No
implementation details, no API call paths, no internal state. Just the user journey.

| Flow | Description |
|------|-------------|
| [Sign In / Sign Up](./sign-in-sign-up.md) | Create an account and sign in |
| [Upload Content](./upload-content.md) | Add a passage from file or pasted text |
| [Study a Passage](./study-passage.md) | Read, simplify, quiz, chat, and delete passages |
| [Translate and Save a Word](./translate-and-save.md) | Quick-translate a selection and save to vocabulary |
| [Browse Dictionary](./browse-dictionary.md) | Look up a word and save it |
| [Review Vocabulary](./review-vocabulary.md) | Review due vocabulary cards with spaced repetition |
| [Track Progress](./track-progress.md) | View streak, time studied, and active days |

For background system behavior and data paths, see [data-flows](../data-flows/).
For navigation between pages, see [ui-flows/navigation-flow.md](../ui-flows/navigation-flow.md).
