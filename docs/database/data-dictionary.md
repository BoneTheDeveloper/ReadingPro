# Data Dictionary

**English Reading Training App - Prisma Schema**

## Identifier Standard

| Identifier kind | PostgreSQL type | Prisma declaration |
|-----------------|-----------------|--------------------|
| Supabase Auth profile ID | `uuid` | `String @id @db.Uuid` |
| Application-owned primary key | `uuid` | `String @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid` |
| Relation/entity-reference ID | `uuid` | `String @db.Uuid` |
| Product/cache/UI key | `text` | `String` |

All `public` table primary keys, foreign keys, and persisted entity-reference
IDs use native PostgreSQL UUIDs. Product keys such as `cacheKey`,
`normalizedKey`, `stripeCustomerId`, and question option IDs remain strings.

## User And Study Tables

### UserProfile (`profiles`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, supplied by Supabase Auth |
| `email` | String? | Unique |
| `name`, `avatarUrl`, `bio` | String? | Optional profile metadata |
| `targetLevel` | CEFRLevel | Default `B2` |
| `tier` | Tier | Default `FREE` |
| `stripeCustomerId` | String? | Unique external billing ID |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

### Passage (`passages`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | UUID | FK -> `profiles.id` |
| `title`, `content` | String | Learner passage |
| `simplifiedContent` | String? | Optional simplified text |
| `originalLevel`, `simplifiedLevel` | CEFRLevel? | Optional CEFR analysis |
| `wordCount` | Int | Original content word count |
| `sourceType` | SourceType | `TEXT` or `PDF` |
| `fileUrl` | String? | Optional storage URL |
| `deletedAt` | DateTime? | Soft-delete timestamp |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

### StudyChatMessage (`study_chat_messages`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | UUID | FK -> `profiles.id` |
| `passageId` | UUID | FK -> `passages.id` |
| `role`, `content` | String | Chat message role and content |
| `createdAt` | DateTime | Creation timestamp |

### Question (`questions`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `passageId` | UUID | FK -> `passages.id` |
| `questionText`, `sourceText`, `explanation` | String | Question content |
| `options` | Json | UI option objects; option IDs remain strings |
| `correctOption` | String | UI option ID, not a public entity ID |
| `sourceLine` | Int | Source line number |
| `questionType` | QuestionType | Default `MULTIPLE_CHOICE` |
| `difficulty` | Int | Default `3` |
| `createdAt` | DateTime | Creation timestamp |

### CardReview (`card_reviews`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|

| `userId` | UUID | FK -> `profiles.id` |

| `easeFactor`, `intervalDays`, `repetitions` | Float / Int | SM-2 state |

### StudySession (`study_sessions`)
