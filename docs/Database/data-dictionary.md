# Data Dictionary

**English Reading Training App - Prisma Schema**

Tables are grouped by the client module they primarily serve. Each model in
`prisma/schema/*.prisma` carries a `///` docstring naming its module and client
surface; this doc mirrors that grouping. Schema files are merged by Prisma, so
the file split is organizational only.

## Identifier Standard

| Identifier kind | PostgreSQL type | Prisma declaration |
|-----------------|-----------------|--------------------|
| Clerk profile ID | `text` | `String @id` |
| Application-owned primary key | `uuid` | `String @id @default(dbgenerated("gen_random_uuid()")) @db.Uuid` |
| Relation/entity-reference ID for app-owned entities | `uuid` | `String @db.Uuid` |
| Relation ID to `profiles.id` | `text` | `String` |
| Product/cache/UI key | `text` | `String` |

Application-owned public table primary keys, foreign keys, and persisted
entity-reference IDs use native PostgreSQL UUIDs. `profiles.id` stores the
Clerk user id as text, so user relations such as `Passage.userId` and
`StudyChatMessage.userId` are text. Product keys such as `cacheKey`, `normalizedText`,
`stripeCustomerId`, Blob pathnames, and question option IDs remain strings.
`StudioArtifact.id` is a UUID supplied by the client, not database-generated.

| `VocabularySetType` | `MANUAL`, `DAILY`, `WEEKLY` | Vocabulary set kind (user list vs auto batch) |

| `StudioArtifact.type` | `quiz`, `flashcard` |
| `StudioArtifact.status` | `generating`, `done`, `failed` |
| `Translation*.provider` | `cache`, `dictionary`, `fallback`, `google_translate`, `ai` |

| `VocabularyItem.status` | `NEW`, `LEARNING`, `MASTERED` |
| `VocabularyItem.source` | `TRANSLATE`, `DICTIONARY` |
| `DictionaryTranslation.status` | `draft`, (reviewed states) |
| `DictionaryAlias.aliasType` | `variant`, ... |

## Identity & Account Module

### UserProfile (`profiles`)

Client: profile/account page, tier gating; implicit owner of all user-scoped data.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | String | PK, the Clerk user id (text, not a generated UUID) |
| `email` | String? | Unique |
| `name`, `avatarUrl`, `bio` | String? | Optional profile metadata |
| `targetLevel` | CEFRLevel | Default `B2`; default passage-simplify target |
| `tier` | Tier | Default `FREE`; gates pro features/quotas |
| `stripeCustomerId` | String? | Unique external billing ID |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

## Study · Sources Module

### Passage (`passages`)

Client: rows in the study sources panel; opening one loads the study workspace.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | String | FK -> `profiles.id` |
| `title`, `content` | String | Learner passage |
| `simplifiedContent` | String? | AI-simplified rewrite; null until simplified |
| `originalLevel`, `simplifiedLevel` | CEFRLevel? | Optional CEFR analysis |
| `wordCount` | Int | Original content word count |
| `sourceType` | SourceType | `TEXT` or `PDF` |
| `filePath` | String? | Unique Blob pathname (PDF sources); server-only |
| `deletedAt` | DateTime? | Soft-delete; non-null rows hidden from list |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

Index: `[userId]`, `[createdAt]`, `[userId, deletedAt]`.

## Study · Studio Module

### StudyChatMessage (`study_chat_messages`)

Client: studio chat panel (per-passage AI thread).

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | String | FK -> `profiles.id` |
| `passageId` | UUID | FK -> `passages.id` |
| `role` | String | `user` or `assistant` |
| `content` | String | Message text |
| `createdAt` | DateTime | Creation timestamp |

### StudioArtifact (`studio_artifacts`)

Client: studio panel cards; generic across artifact types, status drives card state.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, supplied by client (not db-generated) |
| `passageId` | UUID | FK -> `passages.id` |
| `userId` | String | FK -> `profiles.id` |
| `type` | String | `quiz` or `flashcard` |
| `title` | String | Artifact title |
| `status` | String | `generating`, `done`, or `failed` |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

Index: `[passageId, createdAt DESC]`, `[userId]`.

### Question (`questions`)

Client: studio quiz content (question, options, grading, explanation).

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `passageId` | UUID | FK -> `passages.id` |
| `artifactId` | UUID | FK -> `studio_artifacts.id` |
| `questionText`, `sourceText`, `explanation` | String | Question content |
| `options` | Json | UI option objects; option IDs are UI keys, not entity IDs |
| `correctOption` | String | UI option ID (matches `options[].id`), not a public entity ID |
| `sourceLine` | Int | Source line number |
| `questionType` | QuestionType | Default `MULTIPLE_CHOICE` |
| `difficulty` | Int | Default `3` (1-5) |
| `createdAt` | DateTime | Creation timestamp |

### QuizResult (`quiz_results`)

Graded result of a quiz run, coupled 1:1 to the quiz `StudioArtifact`.
Client: studio quiz results screen; also aggregated into the progress dashboard.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `artifactId` | UUID | FK -> `studio_artifacts.id`, unique (one result per quiz) |
| `correctCount` | Int | Correct answers |
| `totalQuestions` | Int | Total questions |
| `accuracyRate` | Float | Computed accuracy |
| `completedAt` | DateTime | Default `now()`, when result was saved |

## Study · Sessions & Progress Module

### StudySession (`study_sessions`)

Tracks study engagement via a client heartbeat. Client: active-session indicator
and time-studied stats on the progress dashboard. Open while `completedAt` is null.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | String | FK -> `profiles.id` |
| `startedAt` | DateTime | When the session opened |
| `lastActivityAt` | DateTime | Last heartbeat (activity / idle signal) |
| `completedAt` | DateTime? | Close time; null means still open |

Index: `[userId, startedAt]`.

## Translation Module

### TranslationCache (`translation_caches`)

Client: instant inline translation when a selection is re-looked-up.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `cacheKey` | String | Unique dedupe key; server-only |
| `userId` | String | FK -> `profiles.id` |
| `sourceId` | UUID | FK -> `passages.id` |
| `selectedText`, `contextSentence` | String | Translation input |
| `sourceLanguage`, `targetLanguage` | String | Language codes |

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | String | FK -> `profiles.id` |
| `sourceId` | UUID | FK -> `passages.id` |
| `selectedText`, `contextSentence`, `translation` | String | Translation record |
| `sourceLanguage`, `targetLanguage` | String | Language codes |
| `mode`, `provider` | String | Lookup mode + backend (see TranslationCache) |
| `response` | Json | Full response payload |
| `createdAt` | DateTime | Creation timestamp |

## Vocabulary Module

### VocabularyItem (`vocabulary_items`)

Client: vocabulary list rows + SRS review queue.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | String | FK -> `profiles.id` |
| `translation`, `sourceLanguage`, `targetLanguage` | String | Vocabulary content |
| `type` | String | `WORD` or `PHRASE` (auto-detected); default `WORD` |
| `normalizedText`, `displayText` | String | Lookup form + display form |
| `status` | String | SRS bucket `NEW`/`LEARNING`/`MASTERED`; default `NEW` |
| `source` | String | `TRANSLATE` or `DICTIONARY`; default `TRANSLATE` |
| `savedCount` | Int | Number of times saved |
| `nextReviewAt`, `lastReviewedAt` | DateTime? | SRS review timestamps |
| `dictionaryEntryId`, `dictionarySenseId` | UUID? | FKs to dictionary tables |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

Unique: `[userId, normalizedText, targetLanguage, translation]`.

### VocabularyOccurrence (`vocabulary_occurrences`)

Client: "seen in" context shown on a saved word.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `vocabularyItemId` | UUID | FK -> `vocabulary_items.id` |
| `sourceId` | UUID? | FK -> `passages.id`; null if not tied to a passage |
| `selectedText`, `contextSentence` | String | Context where word was saved |
| `createdAt` | DateTime | Creation timestamp |

Unique: `[vocabularyItemId, sourceId, contextSentence]`.

### VocabularySet (`vocabulary_sets`)

A named collection of items. `MANUAL` = user list; `DAILY`/`WEEKLY` = auto-built
review batches bounded by `periodStart`/`periodEnd`. Client: vocabulary sets tabs.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | String | FK -> `profiles.id` |
| `name` | String | Set display name |
| `type` | VocabularySetType | `MANUAL`, `DAILY`, or `WEEKLY` |
| `periodStart`, `periodEnd` | DateTime? | Period bounds for auto sets; null for MANUAL |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

Unique: `[userId, type, periodStart, periodEnd]`.

### VocabularySetItem (`vocabulary_set_items`)

Join row placing a vocabulary item into a set.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `vocabularySetId` | UUID | FK -> `vocabulary_sets.id` |
| `vocabularyItemId` | UUID | FK -> `vocabulary_items.id` |
| `addedAt` | DateTime | When the item was added to the set |

Unique: `[vocabularySetId, vocabularyItemId]`.

## Dictionary Module

Shared, app-wide dictionary (not per-user). Client: dictionary lookup panel;
also seeds vocabulary saves.

### DictionaryEntry (`dictionary_entries`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `headword`, `normalizedHeadword` | String | Display and lookup forms |
| `sourceLanguage` | String | Default `en` |
| `frequencyRank` | Int | Default `0`; higher = more common, orders suggestions |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

Unique: `[normalizedHeadword, sourceLanguage]`.

### DictionarySense (`dictionary_senses`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `entryId` | UUID | FK -> `dictionary_entries.id` |
| `partOfSpeech`, `definition`, `example` | String? | Sense content |
| `tags` | String[] | Sense tags |
| `usageRank` | Int | Default `0`; ordering weight (higher first) |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

### DictionaryTranslation (`dictionary_translations`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `senseId` | UUID | FK -> `dictionary_senses.id` |
| `targetLanguage`, `translation` | String | Translation content; `targetLanguage` default `vi` |
| `isPrimary`, `rank`, `confidence` | Boolean / Int / Float? | Preferred flag, priority (lower first), confidence |
| `status`, `sourceType`, `sourceName` | String / String / String? | Review state (default `draft`) + provenance |
| `reviewedAt` | DateTime? | Review timestamp |
| `createdAt`, `updatedAt` | DateTime | Creation/update timestamps |

### DictionaryAlias (`dictionary_aliases`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|

| `entryId` | UUID | FK -> `dictionary_entries.id` |
| `normalizedAlias` | String | Normalized lookup alias |

### DictionarySourceAudit (`dictionary_source_audits`)

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|

| `batchName`, `entityType` | String | Seed/import provenance |

## Upload Module

### FileUploadIntent (`file_upload_intents`)

Short-lived authorization granting expiring access to a private Blob pathname
before the file becomes a Passage. Server-only.

| Column | Type | Constraints / purpose |
|--------|------|-----------------------|
| `id` | UUID | PK, generated by database |
| `userId` | String | FK -> `profiles.id` |
| `pathname` | String | Unique Blob pathname; server-only |
| `expiresAt` | DateTime | Expiration deadline for private upload access |
| `createdAt` | DateTime | Creation timestamp |
